# Fútbol Familia GG
Fútbol arcade de pixel art para jugar en familia, al estilo Nintendo World Cup: seis contra seis visto desde arriba, formaciones, sala de espera con estrategia y clima, un mundo por reino, poderes con cinemática y una Gran Copa.

- Jugar en desarrollo: `npm install && npm run dev`
- Pruebas: `npm test`
- Construir: `npm run build` (la carpeta `dist/` es el juego completo, súbela a cualquier hosting estático)
- Zip con lanzadores para la compu: `bash tools/pack.sh`

Jugadores dibujados en código con el estilo Nekketsu de PixelForja. Ilustraciones generadas con IA y procesadas a 16 bits. Música y sonidos sintetizados en el navegador. Ver `docs/LICENSES.md`.
