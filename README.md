# Fútbol Familia GG
Fútbol arcade de pixel art para jugar en familia. Cinco contra cinco, poderes con cinemática, cuatro reinos y una Gran Copa.

- Jugar en desarrollo: `npm install && npm run dev`
- Pruebas: `npm test`
- Construir: `npm run build` (la carpeta `dist/` es el juego completo, súbela a cualquier hosting estático)
- Zip con lanzadores para la compu: `bash tools/pack.sh`

Arte generado con IA y procesado a 16 bits. Música y sonidos sintetizados en el navegador. Ver `docs/LICENSES.md`.
